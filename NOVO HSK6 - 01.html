Exercícios de Gramática Chinesa:
HSK 6 – NOVA GRAMÁTICA 01 – Expressar “e é tudo” com 而已/罢了

Instruções: Na Parte 1, escolha a opção correta. Na Parte 2, reordene as palavras para formar uma frase correta.

Parte 1 – Escolha múltipla

1. Qual frase significa “Isto não é nada, é apenas um monte de papel”?

2. Qual opção completa corretamente a frase? 不要相信他，这_____是他的借口_____。

3. Qual frase expressa a ideia de que algo “não passa de uma desculpa”?

4. Qual frase utiliza corretamente 只不过……罢了?

5. De acordo com a lição, qual afirmação sobre 而已 e 罢了 está correta?

Parte 2 – Reordenar frases

6. 而已 / 我 / 不过 / 是 / 出于好奇 / 随便问问 / 。

7. 罢了 / 这 / 无非 / 是 / 他的借口 / 。

8. 而已 / 这 / 只是一堆纸 / 。

9. 罢了 / 她 / 只不过 / 假装不会 / 。

10. 而已 / 这 / 不过 / 是 / 一个小问题 / 。
